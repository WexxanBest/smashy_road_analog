# DUSTLINE

Локальный браузерный прототип автомобильной погони: low poly мир, аркадное вождение и оружие с независимым наведением мышью. Рассчитан на компьютер с клавиатурой и мышью.

## Запуск

Установи Node.js с npm, открой терминал в этой папке и выполни:

```powershell
npm install
npm run dev
```

Открой [http://127.0.0.1:5180](http://127.0.0.1:5180). На Windows можно также запустить `start-game.cmd`. Если порт занят, останови предыдущий экземпляр игры. Оставь терминал работающим; для остановки нажми `Ctrl+C`.

Проверка сборки: `npm run build`. Просмотр готовой сборки: `npm run preview`.

## Управление

| Клавиша | Действие |
| --- | --- |
| W / ↑ | Газ |
| S / ↓ | Тормоз, затем задний ход |
| A / D, ← / → | Руль |
| Мышь | Прицел турели |
| ЛКМ | Стрелять из турели |
| 1 / 2 | Выбрать турель / самонаводящиеся ракеты |
| ПКМ | Выстрелить из гранатомёта |
| Shift | Нитро |
| Space | Ручник |
| G | Въехать в ближайший гараж, если хвост сброшен |
| Esc | Пауза / продолжить |
| M | Включить / выключить музыку |
| Tab / клик по мини-карте | Открыть большую карту |

## Как играть

Выбери машину в гараже, настрой цвет и улучшения, затем нажми «Полный газ!». Подбирай добычу и расходники, пользуйся срезами и уходи от преследования. Турель нагревается, гранатомёт расходует боеприпасы, а нитро ограничено запасом. После подбора ракетницы она выбирается автоматически: кликни ЛКМ прямо по машине или вертолёту, и ракета будет следовать за целью. Один клик выпускает одну ракету. При наведении появляются красные уголки вместо обычного прицела; после выстрела рамка следует за целью до попадания или окончания полёта. Турель даёт небольшой толчок машине, качает кузов и откатывает ствол.

Кнопка со значком настроек справа сверху открывает тест вождения. Можно на ходу переключать **Аркаду**, **Баланс**, **Дрифт** и **Сцепление**, а также выключить преследование. Те же настройки доступны по Esc. Баланс — промежуточный режим между Аркадой и Сцеплением. Аркада даёт короткий занос, Дрифт — более длительное скольжение под газом, Сцепление — точные повороты. По умолчанию трафик правосторонний; в настройках можно выбрать левостороннее движение. Настройки сохраняются.

HUD использует выбранное минимальное оформление без больших подложек; над оружием видны клавиши 1, 2 и ПКМ. Короткий туториал показывается при первом выезде; полное управление и легенда предметов остаются в настройках и паузе.

Предметы обозначаются формой и подписью: золотые монеты — +$80, красный ремкомплект — кузов +25 и мотор/шины +15, три гранаты — +3 боеприпаса, синий баллон — нитро +45%, фиолетовая ракетница — +3 ракеты. Критически повреждённый двигатель горит **8 секунд**, затем машина взрывается; ремкомплект или ремонт в гараже прекращает отсчёт.

Пропади из поля зрения полиции, дождись заполнения шкалы ухода от погони и доберись до гаража — он отмечен **G** на мини-карте. Рядом с гаражом нажми **G** или остановись: сохранится вся добыча за заезд. После аварии сохраняется половина. В гараже можно отремонтировать кузов, двигатель и шины, улучшить машину или купить другую.

Прогресс, цвета, улучшения, рекорд и настройка музыки сохраняются в `localStorage` этого браузера. Очистка данных сайта удалит сохранение. Мир получает новый seed после перезагрузки страницы.

Большая карта приостанавливает заезд и показывает территорию, открытую в текущем мире. Перетаскивай её, меняй масштаб колесом или кнопками, кликай для установки точки. Голубой указатель и расстояние на мини-карте показывают направление к выбранному месту; рядом с ним появляется объёмная метка, которая исчезает в радиусе 7 метров. Линия показывает направление напрямую, включая возможные срезы вне дорог. Esc или Tab закрывает карту.

В гараже автомобиль стоит на одном месте: камера плавно меняет полезный ракурс при переходе между вкладками. В мастерской есть подъёмник, антресоль, стеллажи, инструменты и тёплый свет. Город дополнен фасадами, навесами, светящимися окнами, оборудованием крыш, плиткой, мебелью и дорожными объектами.

## Что есть в прототипе

- Процедурный мир с городом, пустыней и полями; гражданский трафик и разрушаемые препятствия.
- Дороги имеют иерархию: извилистые магистрали, отдельные городские районы и редкие грунтовые подъезды к фермам. Гражданский трафик следует изгибам дороги.
- Магистрали плавно соединяются с городскими проспектами; разметка и бордюры учитывают перекрёстки. Парковки находятся внутри кварталов с отдельным въездом, а припаркованные машины можно толкать и повреждать.
- Три автомобиля, покраска, четыре направления улучшений по три уровня.
- Пять уровней розыска, полицейские машины и вертолёты.
- Полицейские заграждения и короткие контракты с наградой за расстояние, скорость, уничтожение преследователей и уход от погони.
- Турель, гранатомёт, нитро; повреждения кузова, двигателя и шин.
- Аркадная модель передних и задних шин: занос от газа/ручника, контрруление, крен кузова и сохраняющиеся парные следы шин. Для входа в занос на скорости зажми руль и коротко Space, затем регулируй поворот и газ.
- Четыре переключаемых варианта вождения. На песке, грунте и траве остаются собственные следы, в том числе при обычной езде; из одной или двух выхлопных труб идёт синий огонь нитро.
- Двери, капот, багажник, бамперы и стёкла отделяются при сильных повреждениях; физические обломки, царапины, треснувшие стёкла, дым и огонь работают у игрока, полиции и трафика. Остовы остаются на дороге на короткое время.
- Объёмная мастерская с рабочими вкладками гаража, выбора машины, тюнинга и кузова. Повреждения видны и в мастерской до ремонта.
- Мини-карта, пауза, результаты заезда и динамическая синтезированная музыка.
- Узнаваемые предметы с подписями, самонаводящиеся ракеты и мелкие объекты мира: скамьи, урны, гидранты, знаки, ящики, кусты и отражающие столбики.
- Babylon.js, TypeScript и физика Havok через WebAssembly; мир подгружается вокруг игрока.

Это игровой прототип: поведение полиции и экономика упрощены, повреждения используют отдельные панели и подготовленные состояния вместо симуляции мягкого кузова. Полноценного мобильного управления и сетевой игры пока нет. Баланс оружия, преследования и экономики ещё можно настраивать.

## Запуск после копирования на Windows

Проект находится в `D:\My coding projects\games\smashy_road_analog`.
Требуется Node.js с npm. Открой PowerShell и выполни:

```powershell
cd 'D:\My coding projects\games\smashy_road_analog'
npm.cmd ci
npm.cmd run dev
```

`npm.cmd ci` нужен при первом запуске и после изменения package-lock.json.
Адрес игры: http://127.0.0.1:5180/. Остановка — Ctrl+C в терминале.
Можно также открыть `start-game.cmd` двойным кликом: при отсутствии зависимостей он установит их сам, затем запустит игру.

Чтобы собрать и локально посмотреть production-версию:

```powershell
npm.cmd run build
npm.cmd run preview
```

## GitHub Pages

Игра подходит для GitHub Pages: HTML, JavaScript, CSS и WASM выполняются на стороне браузера, серверной логики нет.
Для репозитория `smashy_road_analog`, опубликованного по адресу `https://USERNAME.github.io/smashy_road_analog/`, сборка выполняется так:

```powershell
npm.cmd run build -- --base=/smashy_road_analog/
```

Если имя репозитория другое, измени base на его имя. Для сайта USERNAME.github.io в корне домена base должен быть `/`.
В репозитории открой Settings → Pages → Source: GitHub Actions. Готовый workflow находится в `.github/workflows/deploy.yml`: при push в main он выполняет npm ci, проверяет TypeScript, собирает проект с base из настроек Pages и публикует dist. Его также можно запустить вручную из вкладки Actions. В GitHub Actions на Linux используются команды npm без суффикса .cmd. Папка node_modules не загружается в GitHub; dist создаётся при сборке.
Проект пока не опубликован: репозиторий и workflow развёртывания не создавались.
Прогресс хранится в localStorage браузера; сохранение с localhost автоматически на опубликованный адрес не переносится.

Документация: [Vite: GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages), [GitHub: публикация через Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
