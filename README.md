# DUSTLINE

Браузерная игра об автомобильных погонях: процедурный low poly мир, семь машин, полицейские перехватчики, оружие и возвращение в гараж с добычей. Рассчитана на компьютер с клавиатурой и мышью.

## Запуск и проверка

Установи Node.js с npm, открой терминал в этой папке и выполни:

```powershell
npm install
npm run dev
```

Открой [http://127.0.0.1:5180](http://127.0.0.1:5180). На Windows можно также запустить `start-game.cmd`. Если порт занят, останови предыдущий экземпляр игры. Оставь терминал работающим; для остановки нажми `Ctrl+C`.

Проверка TypeScript и сборка: `npm run build`. Просмотр готовой сборки: `npm run preview`.

Проверка правил прогресса, преследования, трафика, наведения, охлаждения, моделей, разрушений мира и инерции остовов в Havok:

```powershell
npm run test
```

Эти проверки дополняют ручную проверку в браузере: визуальное падение вертолёта, обзор камеры и ощущения от вождения оцениваются в самой игре.

## Первый заезд и гараж

Новая игра начинается с **COMET MK2 без турели** и 800 $. Выбери цвет, при необходимости настрой вождение, затем нажми «Полный газ!». Ракеты и гранатомёт доступны независимо от покупки турели; боеприпасы собираются на дороге. При переносе старого сохранения ранее доступная турель сохраняется.

Подбирай добычу, выполняй контракты, используй переулки и срезы. Чтобы уйти от полиции, пропади из её поля зрения и дождись заполнения шкалы отрыва. Затем доберись до гаража, отмеченного **G** на мини-карте, и нажми G или остановись рядом: вся добыча за заезд перейдёт на баланс. После аварии сохраняется половина добычи. Полный ремонт кузова, двигателя и шин стоит 150 $.

В мастерской четыре вкладки: **Гараж**, **Автомобили**, **Тюнинг**, **Кузов**. Баланс виден в каждой из них, включая узкое окно. Камера показывает разные ракурсы выбранной машины; повреждения остаются видимыми до ремонта. Можно выехать на другой своей машине, сохранив состояние прежней в течение текущего заезда.

## Машины и задания

В игре семь разных кузовов. DUNE SCOUT и SANDFOX меньше теряют сцепление вне асфальта. Новые машины за задания выдаются бесплатно; покупать их за деньги не требуется.

| Машина | Тип | Как получить |
| --- | --- | --- |
| COMET MK2 | Лёгкий городской хэтчбек | Доступен с начала игры |
| DUNE SCOUT | Внедорожник | Купить за 1 800 $ |
| BRUTE RUNNER | Тяжёлый пикап | Купить за 3 200 $ |
| KESTREL | Лёгкое купе | «Первый маршрут», лёгкое: проехать суммарно 2 000 м в обычных заездах |
| SANDFOX | Багги | «Вне дорог», среднее: проехать суммарно 1 500 м по грунту, полям или песку |
| COBRA | Маслкар | «Полминуты на пределе», сложное: держать не менее 80 км/ч 30 секунд подряд в одном обычном заезде |
| BASTION | Бронированный фургон | «Последний выход», экспертное: уйти от погони с 5 звёздами и вернуться в гараж |

Карточки заданий и прогресс доступны в каталоге машин и настройках. Накопленные расстояния и выполненные задания сохраняются между заездами. В песочнице задания и награды обычной игры не изменяются. Короткие контракты на расстояние, скорость, уничтожение преследователей и отрыв дополнительно приносят деньги.

## Улучшения и вооружение

У каждой машины пять отдельных веток по три уровня. Карточка улучшения показывает цену и числовой эффект до и после установки.

| Ветка | Эффект каждого уровня |
| --- | --- |
| Двигатель | +8,5% к базовому пределу скорости и +10% к мощности |
| Броня | +30 HP к прочности; также уменьшает получаемый урон |
| Шины | +6,5% к коэффициенту бокового сцепления и +3,5% к пределу бокового ускорения |
| Управляемость | +10% к скорости отклика руля и +5% к пределу бокового ускорения |
| Нитро | Расход меньше на 4 единицы/с, восстановление быстрее на 2 единицы/с |

Проценты суммируются относительно базового значения, поэтому третий уровень двигателя даёт +25,5% к пределу скорости. Реальная скорость и поведение зависят также от повреждений, поверхности, выбранного профиля вождения и нитро. Управляемость улучшает отклик и устойчивость, сохраняя особенности самого автомобиля.

В разделе **Тюнинг → Вооружение** купи турель за **1 200 $**. Это одна общая покупка для всех своих машин; установка и снятие бесплатны и выбираются отдельно для каждой машины. Турель не появляется автоматически на всех кузовах.

У турели есть отдельное общее улучшение охлаждения: три уровня дают **+15%, +30%, +45%** к скорости остывания для всех установленных турелей. Оно помогает быстрее вернуться к стрельбе после нагрева; темп самих выстрелов не увеличивается. Боезапас турели не ограничен, но длительная стрельба вызывает перегрев. Выстрелы визуально качают кузов и откатывают ствол.

Ракеты пополняются на дороге. **Подбор ракет не меняет выбранное оружие**: нажми **2**, наведи на видимую машину или вертолёт и кликни ЛКМ. Один клик выпускает одну ракету. Уголки захвата отмечают цель; выпущенная ракета следует за ней до попадания или окончания полёта. Препятствия могут перекрывать выстрел и полёт ракеты.

Помощь наведения настраивается **отдельно для турели и ракет**: выключена, слабая или стандартная. При выключенной помощи требуется точное наведение; самонаведение уже выпущенной ракеты сохраняется.

## Погоня, повреждения и предметы

С ростом розыска появляются новые роли: обычный патруль, быстрый перехватчик, внедорожник и тяжёлый SWAT. Они отличаются скоростью, прочностью, массой и поведением. Заграждения входят в общий лимит полицейских машин.

| Розыск | Машин одновременно, до | Состав подкреплений | Авиация | Пауза замены сбитого вертолёта |
| --- | --- | --- | --- | --- |
| 1★ | 3 | Патрули | Нет | — |
| 2★ | 4 | Патрули и перехватчики | Нет | — |
| 3★ | 5 | Добавляются внедорожники | До 1 наблюдателя | 60 с |
| 4★ | 6 | Добавляется SWAT | До 1 вооружённого вертолёта | 50 с |
| 5★ | 8 | Смешанные подразделения | До 2 вооружённых вертолётов | 40 с |

Авиация вводится с задержкой; на 5★ второй вертолёт приходит отдельно. Сбитые не заменяются следующим кадром. У вертолётов разные высоты и орбиты, а здания могут закрыть игрока от наблюдения. Подкрепления и движущийся гражданский трафик создаются за пределами видимой области камеры; постоянные парковки и стартовые расходники уже являются частью мира.

Гражданские машины следуют полосам, учитывают попутные автомобили и прогнозируют опасные сближения, замедляясь перед столкновением. Это упрощённое поведение, поэтому аварии всё ещё возможны. По умолчанию движение правостороннее; сторону можно изменить в настройках.

Повреждения видны на кузове: царапины, треснувшие стёкла, потерянные двери, капот и бамперы, дым и огонь. При критической прочности начинается **8-секундный отсчёт до взрыва**. Ремкомплект восстанавливает машину и сбрасывает отсчёт; полный ремонт в гараже тушит огонь. Горящая полицейская или гражданская машина перестаёт преследовать/ехать и тормозит; сгоревшие остовы сохраняют скорость и вращение в момент взрыва, затем постепенно останавливаются от сопротивления и контактов с дорогой. Взрывы и тараны могут снова сдвигать их.

Сбитый вертолёт теряет управление, кренится и падает с дымом. При ударе отделяются корпус, хвост, винт и полозья, происходит взрыв; крупные физические обломки остаются ненадолго. Это постановочная игровая последовательность с физикой отделившихся частей.

| Предмет | Эффект |
| --- | --- |
| Золотые монеты | +80 $ к добыче заезда |
| Красный ремкомплект с крестом | Кузов +25 HP, двигатель и шины +15 |
| Гранаты | +3 боеприпаса гранатомёта |
| Синий баллон | Нитро +45 единиц |
| Фиолетовые ракеты | +3 ракеты без смены оружия |

## Мир и карта

Процедурный мир состоит из города, пустыни и полей. Магистрали соединяются с проспектами, кварталами и редкими грунтовыми подъездами к фермам. Внутри кварталов есть парковки с въездами; припаркованные машины можно толкать и повреждать.

На улицах и за городом встречаются скамьи, урны, гидранты, ящики, знаки, ограждения, бочки, объекты заправок и другие препятствия. Часть объектов сдвигается от удара, часть ломается и оставляет обломки; взрывоопасные объекты могут вызвать цепную реакцию. Движение небольших предметов рассчитывается упрощённо, с сопротивлением и проверками ближайших крупных препятствий.

Витрины и навесы повреждаются отдельно от здания. Небольшие подготовленные постройки могут переходить в состояние развалин; крупные здания получают видимые повреждения и остаются несущими препятствиями. Полного разрушения любого дома нет. Ветряные турбины вращаются, а повреждения влияют на их состояние. Крупные объекты, закрывающие машину от камеры, плавно становятся полупрозрачными; это улучшает обзор, но не отменяет столкновения и укрытие от огня.

**Большая карта** приостанавливает заезд и показывает открытую в текущем мире территорию. Перетаскивай её, меняй масштаб колесом или кнопками и кликай для установки точки. Голубой указатель показывает направление к месту; вблизи появляется объёмная метка. Линия идёт напрямую и не строит маршрут с учётом дорог. Esc или Tab закрывает карту.

## Настройки, музыка и песочница

Открой ⚙ в гараже, настройки справа сверху во время заезда или меню паузы. Четыре профиля вождения можно переключать на ходу: **Аркада**, **Баланс**, **Дрифт**, **Сцепление**. Для заноса зажми руль и ненадолго ручник, затем регулируй газ и контрруление. На песке, траве и грунте сцепление отличается от асфальта, а колёса оставляют соответствующие следы.

Музыка синтезируется в игре: спокойные слои в гараже и свободной поездке, более интенсивные при погоне и отдельный переход после отрыва. Музыкальные слои и темп меняются по тактам. **Музыка, эффекты и двигатель имеют отдельные регуляторы громкости**; выключение музыки клавишей M сохраняет звуки машины и выстрелов.

**Песочница** запускает отдельный экспериментальный сеанс с доступом ко всем машинам, турелям и тестовым деньгам. Можно включить бессмертие, бесконечное нитро, бесконечные ракеты/гранаты и турель без перегрева. Розыск задаётся вручную от 0 до 5 либо возвращается к обычным правилам. Переключение режима завершает текущий заезд.

Покупки, деньги, рекорды и задания песочницы **не записываются в обычное сохранение**. При выходе восстанавливается обычный прогресс. Настройки вождения и прицеливания остаются общими настройками игры.

## Сохранение и ограничения

Машины, баланс, цвета, улучшения, оборудование, задания и рекорд хранятся в `localStorage` этого браузера; настройки управления и звука также сохраняются. Очистка данных сайта удаляет сохранение. Старые сохранения приводятся к новой структуре с сохранением доступных машин и турели. Мир получает новый seed после перезагрузки страницы; карта исследования и изменения объектов относятся к текущему миру.

Игра использует Babylon.js, TypeScript и Havok через WebAssembly. Мир подгружается вокруг игрока; управление автомобилями обновляется на фиксированном физическом шаге, отображение и камера сглаживаются.

Это прототип: экономика и тактика полиции упрощены, а дорожный AI не гарантирует отсутствие аварий. Кузова и здания повреждаются с помощью отдельных частей и подготовленных состояний. Мелкие предметы используют упрощённую динамику, не все декоративные детали имеют отдельное взаимодействие. Число обломков и время их жизни ограничены; полного обрушения зданий, симуляции мягкого кузова, сетевой игры и полноценного мобильного управления пока нет.

## Запуск после копирования на Windows

Проект находится в `D:\My coding projects\games\smashy_road_analog`.
Требуется Node.js с npm. Открой PowerShell и выполни:

```powershell
cd 'D:\My coding projects\games\smashy_road_analog'
npm.cmd ci
npm.cmd run dev
```

`npm.cmd ci` нужен при первом запуске и после изменения package-lock.json.
Адрес игры: http://127.0.0.1:5180/. Остановка — Ctrl+C в терминале.
Можно также открыть `start-game.cmd` двойным кликом: при отсутствии зависимостей он установит их сам, затем запустит игру.

Чтобы собрать и локально посмотреть production-версию:

```powershell
npm.cmd run build
npm.cmd run preview
```

## GitHub Pages

Игра подходит для GitHub Pages: HTML, JavaScript, CSS и WASM выполняются на стороне браузера, серверной логики нет.
Для репозитория `smashy_road_analog`, опубликованного по адресу `https://USERNAME.github.io/smashy_road_analog/`, сборка выполняется так:

```powershell
npm.cmd run build -- --base=/smashy_road_analog/
```

Если имя репозитория другое, измени base на его имя. Для сайта USERNAME.github.io в корне домена base должен быть `/`.
В репозитории открой Settings → Pages → Source: GitHub Actions. Готовый workflow находится в `.github/workflows/deploy.yml`: при push в main он выполняет npm ci, проверяет TypeScript, собирает проект с base из настроек Pages и публикует dist. Его также можно запустить вручную из вкладки Actions. В GitHub Actions на Linux используются команды npm без суффикса .cmd. Папка node_modules не загружается в GitHub; dist создаётся при сборке.
Репозиторий: https://github.com/WexxanBest/smashy_road_analog. Адрес игры после успешного deployment: https://wexxanbest.github.io/smashy_road_analog/. GitHub Actions автоматически публикует обновления из ветки main.
Прогресс хранится в localStorage браузера; сохранение с localhost автоматически на опубликованный адрес не переносится.

Документация: [Vite: GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages), [GitHub: публикация через Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
