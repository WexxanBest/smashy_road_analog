# 3D концепты DUSTLINE

Галерея: `http://127.0.0.1:5180/design-review/gallery.html` после `npm run dev` из корня проекта.
Галерея использует установленный Babylon.js через Vite; внешние шрифты, CDN и текстуры не нужны.

| Модель | Назначение | Треугольников без турели | Детальных mesh-узлов |
|---|---|---:|---:|
| `comet-mk2.gltf` | Компактный городской хэтчбек, оранжевый референс | 6 916 | 152 |
| `dune-scout.gltf` | Высокий внедорожник, запаска, силовой бампер, рейлинги | 11 860 | 245 |
| `brute-runner.gltf` | Тяжелый пикап с открытым грузовым кузовом | 10 208 | 206 |
| `interceptor.gltf` | Отдельный полицейский седан, контрастная ливрея и маяки | 6 956 | 154 |
| `wind-turbine.gltf` | Ветротурбина с отдельным ротором и анимацией | 320 | 8 |
| `removable-turret.gltf` | Съемный модуль вооружения; основание в локальном нуле | 376 | 8 |

Все glTF — настоящая геометрия в формате 2.0, со встроенным base64 буфером. Файл переносится отдельно, соседние файлы ему не нужны. Материалы PBR с цветом, шероховатостью и металлическим параметром; освещение и пол галереи в ассеты не включены. Текстур и UV-развертки нет. Модели используют метры, Y вверх, нос автомобиля +Z. Это концепты, геометрия создана специально для проекта по предоставленным визуальным пожеланиям.

Внутри каждой машины раздельны кузов, кабина, стекла, расширители арок и четыре колесных узла. Колеса можно вращать вокруг локальной X, передние колесные группы — поворачивать вокруг Y. У машин нет постоянной турели. В просмотрщике ее можно включить и скачать автомобиль вместе с ней; кнопка скачивания учитывает выбранный цвет. Отдельный файл турели имеет точку крепления `[0, 0, 0]`; высота крепления для COMET — 1,75 м, DUNE — 2,10 м, BRUTE — 2,00 м. Для полицейского седана турель отключена из-за световой балки.

У ветротурбины узел `Ротор — вращение вокруг Z` содержит три лопасти и кок. В glTF записан один полный оборот за 8 секунд. Зацикливание включает импортирующий движок; сама галерея вращает ротор программно. Для турбины применяются авторские светлые материалы, изменение цвета кузова отключено.

## Воспроизведение

```powershell
node design-review/models/generate-models.mjs
```

Источник геометрии и экспортер: `model-library.mjs`. Генератор создает перечисленные файлы и `manifest.json`, затем проверяет границы буфера, выравнивание, диапазоны индексов, единичные нормали, направление треугольников и иерархию. Внешние пакеты экспорта не используются. Это локальная структурная проверка, не сертификация официальным glTF Validator.

Грани исходной геометрии используют CCW, как glTF. В Babylon-просмотрщике включена правосторонняя система координат; для каждого raw `Mesh` явно задано `sideOrientation = Material.CounterClockWiseSideOrientation`. Это важно: Babylon по умолчанию ставит raw Mesh в RH-сцене CW, а автоматическая компенсация встроенных MeshBuilder не применяется к нашим буферам. Менять winding в glTF ради просмотрщика не нужно.

## Перед подключением в игру

Эти модели еще не связаны с Havok, управлением, уроном, оружием и сохранением прогресса. Размеры и центр массы нужно согласовать с игровыми коллайдерами; колесные группы и турель подключить к существующей логике. Пропорции машин различны по конструкции, а не по масштабу одного кузова.

Количество mesh-узлов намеренно велико для редактирования отдельных деталей. Перед массовым использованием в городе следует объединить неподвижные детали по материалам, сохранив отдельные колеса и вооружение, и подготовить упрощенный LOD. Collision mesh, LOD, запеченные текстуры и анимация подвески пока не созданы. Поведение основной игры не менялось.
